## What I ship

| Project | What it is |
| :--- | :--- |
| ☁️ **[Nimbus](https://github.com/Shernnan/Nimbus)** | Autonomous Win32 graphical terminal built in **pure C**. 60 FPS math-driven RGB text rendering using GDI double-buffering to eliminate screen flicker. Optimized for TCC. |
| ⚙️ **[JS-Automation-Tools](https://github.com/Shernnan/js-automation)** | Custom **JavaScript/Node.js** scripts and workflows designed to automate file system management, data parsing, and repetitive OS-level tasks. |
| 🎵 **[Audio-Lyrics-Core](https://github.com/Shernnan/audio-core)** | Digital audio production repository containing original chord progressions. |
| 🎥 **[Media-Production-Assets](https://github.com/Shernnan/media-assets)** | Automated video rendering templates, intro assets, and metadata workflows optimized for fast content creation and digital channel curation. |
